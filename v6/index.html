Findings Kritis

  • 9 PIC hilang di V4 jobdesk.json (Yudi, Sdek, Amir, Novita, Rizal, Sinta, Reni, Rifki, Reta invisible).
  • PIN default 0000 flat untuk seluruh karyawan = no auth.
  • Reward table mismatch: V4 = 4+4 jenis, PROGRAM KERJA BAB 8 = 6 reward + 12 punishment.
  • Notion DBs semua kosong (per memory project-buku-mgt-dashboard-kacau).
  • Tidak ada reporting line / parent_id → command chain putus.
  • Tidak ada audit trail perubahan status.
  • Tidak ada reminder otomatis, karyawan harus buka manual.
  • Tidak ada real-time update, data static.
