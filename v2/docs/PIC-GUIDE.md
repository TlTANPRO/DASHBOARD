# PIC GUIDE · Dashboard V2.1

> Untuk **12 PIC** PT Syahfalah + Lembayung — input jobdesk + KPI harian.

## Login

1. Buka `https://tltanpro.github.io/DASHBOARD/v2/`
2. Klik **Login** (pojok kanan atas)
3. Pilih **nama Bapak/Ibu** dari dropdown
4. Masukkan **PIN 4 digit** (diberikan owner via WA — JAGA KERAHASIAAN)
5. Setelah login → section V2 (KPI / Program / Jobdesk / SOW) terbuka

## Jobdesk Harian (WAJIB setiap hari)

1. Klik nav **★ Jobdesk Harian**
2. Filter default = hari ini. Set tanggal manual kalau perlu
3. Klik **+ Tambah Jobdesk** → isi:
   - **Jobdesk**: kerjaan apa (contoh: "Brief mandor 2 site")
   - **Target Output**: hasil yang diharapkan (contoh: "2 site terbrief")
   - **Prioritas**: P1 (penting), P2 (normal), P3 (kalau sempat)
   - **Kategori**: Harian / Mingguan / Bulanan
4. Setelah selesai kerjaan → klik row → **Edit** → ubah Status ke **Done**, isi **Actual Output**
5. Status ada 4: **To Do** (belum mulai), **In Progress** (sedang), **Done** (selesai), **Blocked** (ada halangan)

## KPI Tracker (Bulanan)

1. Klik nav **★ KPI Tracker**
2. Lihat KPI Bapak/Ibu yang sudah di-set (oleh Mada atau owner)
3. Update **Realisasi** angka + **Status** tiap akhir minggu / akhir bulan
4. **Catatan** wajib diisi untuk status At Risk / Off Track (supaya owner paham)
5. **Bukti**: link Google Drive / foto / spreadsheet (opsional tapi sangat membantu)

## SOW (Scope of Work)

1. Klik nav **★ My SOW** → filter otomatis ke nama Bapak/Ibu
2. View only — SOW diset oleh owner / Mada, tidak bisa edit sendiri
3. Kalau ada SOW yang tidak relevan → kasih tahu owner via WA

## Program Kerja (Q3 2026)

1. Klik nav **★ Program Kerja**
2. Filter Quarter = Q3 (default)
3. PIC Penanggung Jawab bisa update **Progress (%)** dan **Status**
4. **Risiko** wajib diisi kalau status At Risk / Delayed

## Conflict 409

Kalau Bapak/Ibu edit row yang baru saja diedit orang lain → muncul pesan **"Data sudah diubah"**:

1. **Refresh** halaman (Ctrl+Shift+R)
2. Lihat versi terbaru
3. Edit lagi kalau masih perlu

Kalau Bapak/Ibu yakin data perlu di-override → hubungi owner.

## Tips Harian

- **Pagi (08:30)**: tambah jobdesk hari ini (3-5 row, P1 duluan)
- **Siang (12:00)**: update yang In Progress → Done / Blocked
- **Sore (16:30)**: final update + cek esok hari
- **Jumat sore**: review mingguan, update KPI Mingguan kalau ada

## FAQ

**Q: PIN ditolak?**
A: Pastikan 4 digit sesuai pesan owner. Case sensitive tidak, tapi angka harus match.

**Q: Tidak bisa edit?**
A: Hubungi Mada. Mungkin session expired (12 jam) atau ada perubahan role.

**Q: Data ilang?**
A: Cek dulu di Notion langsung (via link di Notion). Dashboard sync dari Notion, bukan sumber utama.

**Q: Jobdesk kemarin lupa input?**
A: Bisa! Ganti tanggal di filter, tambah jobdesk dengan tanggal kemarin, save. Status langsung tersimpan.
